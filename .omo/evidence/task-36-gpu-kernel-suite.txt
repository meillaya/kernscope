THE REGISTER_PASS CONTRACT (verbatim from register_pass.h, abbreviated)
-----------------------------------------------------------------------
PassRegistry: singleton holding
std::vector<std::function<void(llvm::PassBuilder&)>> callbacks_;
(registerCallback / callbacks accessors; PassRegistrar ctor appends).
Macro:
#define REGISTER_PASS_CALLBACK(CallbackLambda)                          \
  static ::kernscope::pass::PassRegistrar kernscope_pass_register_##__COUNTER__(\
      CallbackLambda)
Module contract: each pass module (tools/pass/passes/<name>/) defines its
PassInfoMixin pass(es) in its own dir and at file scope of one of its .cpp
files calls REGISTER_PASS_CALLBACK([](llvm::PassBuilder &PB){ ... }) which
wires (a) registerPipelineParsingCallback for `opt -passes=kernscope-<name>`
and (b) EP callbacks (registerPipelineStartEPCallback / registerPeepholeEP
Callback / ...) for auto-run under clang -fpass-plugin and
opt -passes=default<O2>. src/plugin.cpp never names a pass — it iterates
PassRegistry::instance().callbacks() with the PassBuilder at dlopen time.
No shared-file edits needed by todos 37-41 (their stub CMakeLists exist).

RISKS / DEVIATIONS
------------------
1. MODULE libs DO get the "lib" prefix under CMake 4.3.4 by default —
   set PREFIX "" to match the in-tree Bye.so convention; path pinned in
   lit site cfg (build/lib/kernscope-pass.so).
2. nix clang wrapper breaks nvptx device compiles (-mtls-dialect= etc.) —
   lit.cfg.py unwraps it (verify ingester parity); documented in file.
3. clang 21 only enables CUDA keywords when it DETECTS an installation:
   -nocudainc demotes to C++ (__global__ unknown). Synthetic staged root
   (verify's stage_cuda_root recipe) + -nocudalib, no -nocudainc.
4. lit RUN lines must quote 'default<O2>' for the test shell.
5. REAL cross-version C++ ABI mismatch (plugin built vs LLVM 19 loaded in
   opt-21) SEGFAULTS — LLVM only guards the struct layout via APIVersion
   (research brief §1.2); graceful failure is asserted via the version-
   guard + entry-point-guard fixtures (negative evidence file).
