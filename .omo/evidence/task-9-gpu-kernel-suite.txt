DEVIATIONS / NOTES
  * kernscope-ptxdump target is defined in libs/ptxparse/CMakeLists.txt (not
    tools/ptxdump/CMakeLists.txt) per deliverable-1 wording; root CMakeLists
    adds only add_subdirectory(libs/ptxparse).
  * ptxdump JSON uses kernscope::db::json (libs/db, no external dep; canonical
    lexicographic key order). class_counts keys are stable single-word names.
  * CFG fallthrough edge is represented by the next block's LABEL; a
    fallthrough into an unlabeled block adds no successor string (edge count
    reflects labeled targets only). Predicated @p bra contributes target +
    labeled fallthrough; unconditional bra contributes its target only;
    ret/exit contribute none.
  * mem_width_counts covers ld/st classes (type suffix bits, e.g. v4.f32 = 32).
  * tcgen05.ld/st (tensor-memory ops) are tracked in tensor_ops, not in the
    ld/st state-space access counters.
  * Non-entry .func bodies parse into kernels() with entry_point=false.
