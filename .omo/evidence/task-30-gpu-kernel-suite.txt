TOOLCHAIN NOTES / DEVIATIONS (all deterministic, documented in
tools/verify/README.md + tests/fixtures/README.md)
  1. clang 21 single -emit-llvm runs fatbinary on the device bitcode
     ("fatbinary elf mismatch", todo-5 evidence) -> ingestion runs
     --cuda-host-only + --cuda-device-only passes and merges the IR in
     process with LLVM's Linker. Host+device still land in ONE module
     (the plan contract); --cuda-device-only is NEVER the default.
  2. Launch-site resolution pairs __cudaPushCallConfiguration(constant
     dims) -> __cudaPopCallConfiguration -> cudaLaunchKernel/hipLaunchKernel
     in program order; kernel mapping via demangle-based __device_stub__
     resolution (naive mangled-name surgery is unsound: parameter letters
     like 'P' are alphanumeric).
  3. HIP path uses the UNWRAPPED clang 21 with --hip-path=<ROCm root>
     (hipcc's bundled hipClang emits 1-arg lifetime intrinsics that LLVM
     21's parser rejects); HIP host module's kernel-alias global
     (@kernel = constant ptr @__device_stub__kernel) is retargeted to the
     host stub pre-link; device appending globals (@llvm.compiler.used in
     addrspace(1)) are dropped pre-link. HIP test is compile-gated.
  4. -gline-tables-only added to ingestion so Diagnostics carry DebugLoc
     source locations.
