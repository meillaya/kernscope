Design notes:
- Launch-config discovery: manifest.json next to the input seeds arch /
  block_size / ptxas_v_report (the golden's 102-register figure drives the
  pinned occupancy 0.375); CLI flags override the manifest.
- AMDGPU path runs the five AmdModule analysis overloads; occupancy +
  suggestion engine (PTX-specific) emit documented not-applicable info
  findings instead of crashing (limiter "not-modeled").
- lit 18 defaults pipefail on and tool substitutions are word-boundary
  regexes; tests capture reports into %t.json and FileCheck the file, so
  the CLI's exit-1-with-warnings (a successful analysis) does not fail the
  pipeline while exit-2/3 errors still fail via FileCheck on empty output.
