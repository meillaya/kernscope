DEVIATIONS / FINDINGS (documented in-code too)
----------------------------------------------
1. find_package(LLVM 21 REQUIRED CONFIG) FAILS against the nixpkgs toolchain:
   nixpkgs patches LLVMConfigVersion.cmake to strict major.minor matching
   ("LLVM is API-compatible only with matching major.minor versions"), so a
   request for "21" (i.e. 21.0) is rejected for 21.1.8. Used
   find_package(LLVM 21.1 REQUIRED CONFIG) instead - same intent (LLVM-21
   family), works with the store toolchain.
2. lit 18.1.8's use_default_substitutions() does NOT define %llvm_tools_dir;
   added the substitution explicitly in lit.cfg.py (FileCheck/opt discovered
   via LLVM_TOOLS_BINARY_DIR -> config.llvm_tools_dir).
3. Kernscope tools land in build/bin via RUNTIME_OUTPUT_DIRECTORY (tt-flow
   convention) so lit's KERNSCOPE_TOOLS_DIR finds them.
4. scripts/configure.sh probes `devenv shell` readiness (timeout 90) before
   re-exec'ing into it, so a mid-materialization devenv (todo 2 in progress)
   falls back to nix-store paths instead of hard-failing.
5. Hardware features on this machine: /dev/kfd present -> gpu-amd active;
   nvcc NOT on bare PATH (comes from the devenv) -> gpu-nvidia-rental inactive
   outside the shell; gfx1101 detection wired via rocminfo when present.
