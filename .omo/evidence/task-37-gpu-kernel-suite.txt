THE TRANSFORM
-------------
Scalar global load/store chains -> vector loads/stores (width 2 or 4,
4..16 bytes total), NVPTX IR in -> NVPTX IR out, when ALL provable:
  * contiguity:  SCEV difference of consecutive chain addresses folds to a
                 constant == element size (works inside loops where the
                 chain base is an induction expression).
  * alignment:   chain head aligned to the vector byte width =
                 min(getKnownAlignment(underlying object),
                     2^SCEV.getMinTrailingZeros(head offset SCEV)). The
                 strided-contiguous loop (a + 16*i elements/iter) has
                 {0,+,64}-byte offsets -> 16B provable -> <4 x float>.
  * address space: v1 = addrspace(1) (NVPTX global) ONLY; addrspace(3)
                 (shared) flagged future work.
  * aliasing:    chains grouped per getUnderlyingObject; a rewrite happens
                 only when no intervening memory instruction (call/store/
                 load/atomic/fence) may alias ANY merged location
                 (AAResults getModRefInfo) — the plan's MUST-NOT guard.
  * element types: scalar int/float 8/16/32/64 bits; simple (non-volatile,
                 non-atomic) accesses only.
Rewritten loads: load <w x T> at the head + extractelement per element;
rewritten stores: insertelement chain + store <w x T> at the last store.
Explicit align = w*e on the vector access.
