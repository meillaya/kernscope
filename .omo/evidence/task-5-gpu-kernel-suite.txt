NOTES / DEVIATIONS FROM THE BRIEF
  1. The nix CUDA packages split the toolkit: cudart lacks bin/, nvvm/libdevice
     and nvcc-internal crt/ headers; cuda_curand is absent. clang 21's detector
     requires include/ + bin/ + nvvm/libdevice and its runtime wrapper
     force-includes curand_mtgp32_kernel.h. The gate stages a synthetic
     single-root CUDA layout + a minimal test-owned curand shim (no NVIDIA
     header vendored). Documented in tests/fixtures/README.md.
  2. The nix clang wrapper bakes host-only flags (-mtls-dialect=gnu2 etc.) that
     nvptx64 rejects -> the gate uses the UNWRAPPED clang 21.1.8 binary.
  3. clang 21 with -emit-llvm runs fatbinary on the device .bc (elf mismatch)
     -> the gate splits into --cuda-host-only (launch syntax) +
     --cuda-device-only (__syncthreads -> llvm.nvvm.barrier*); clang 21 lowers
     __syncthreads to llvm.nvvm.barrier.cta.sync.aligned.all (new intrinsic name).
  4. clang 21 emits the legacy cudaConfigureCall stub when no CUDA>=9 SDK
     version is visible on the host target; the declaration is nvcc-internal,
     so clang_cuda_smoke.cu declares it and uses <<<4, 256, 0, 0>>>.
  5. fused_attention.cu uses dynamic shared memory (66 KiB extern __shared__)
     because the 66 KiB tile set exceeds the 48 KiB static limit (real
     flash-attention pattern; nvcc would otherwise demote the arrays).
  6. bf16 RNE in layernorm.hip is a manual bit-exact implementation, verified
     0 mismatches over 100008 random + special values vs ml_dtypes.bfloat16.
  7. Fixture size: 2 MB total (ptx 137 KB, npz pair 788 KB, hip source small).
