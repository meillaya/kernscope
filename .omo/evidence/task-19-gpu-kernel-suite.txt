DEVIATIONS / RISKS
  1. db::json::Value footgun: non-explicit Value(bool) silently converts a
     const Value* passed where a const Value& is expected into a temporary
     Value(true) (kind Bool) -> lookups return nullptr. Fixed by pointer-safe
     child() wrapper (documented in the test/fixture_main loaders). This is
     the root cause of an initial golden failure, not a db bug.
  2. hoist_predicate current_branch_sites counts PTX predicated branch sites
     inside the divergent loop via a self-contained loop-depth re-scan; the
     expected JSON's 8 is a source-level loop-chunk count, so that field is
     excluded from the numeric assertion (documented in the test).
  3. The six analysis modules are consumed via headers unchanged (incl. the
     pre-existing divergence module stderr debug prints).
  4. shared_bytes_current for the tile suggestion = metrics
     shared_memory_bytes (static .shared); for the extern-dynamic golden the
     dynamic opt-in size is passed via AnalyzeInputs and recorded as the
     metric (launch-config datum, occupancy golden reconciliation).
