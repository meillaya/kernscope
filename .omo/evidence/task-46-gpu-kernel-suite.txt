v0 -> v1 COMPATIBILITY DECISION (docs/capture-format.md SS7):
  v1 is an UPGRADE LAYER, not a replacement. create_v0() keeps its exact
  deterministic text output (the todo-43 smoke + todo-44 equivalence
  assertions depend on it) and the existing mechanisms (shim/cupti-sub/
  capture-hip) keep emitting v0 - this todo MUST NOT modify them. The
  BundleReader loads BOTH: v1 *.kcap/ directories AND the v0 line-oriented
  text shape todos 43/44/45 produce (incl. *.bin sidecar input blobs from
  the todo-44 equivalence bundles). Record semantics are frozen (v1 event
  types mirror the v0 line tokens; v1 adds only seq + param_info).
